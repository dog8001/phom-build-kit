# PHOM — Pierre Human Operating Model
## Canonical Build Context v1.0

Purpose:
Build a high-fidelity, evidence-based, living human operating model of Pierre Carlsson.

The system should function as:
1. Self-understanding engine
2. Decision-support engine
3. Predictive behavioral model
4. Development and anti-sabotage system
5. High-fidelity representation / Pierre-like reasoning layer
6. Long-term living raw-data repository

## Locked Design Principles

1. Evidence First
Observed behavior > self-description.

Trust priority:
- High trust: actual decisions, repeated behavioral patterns, written texts, long-term historical evidence, repeated contradictions, observed outcomes.
- Medium trust: self-reflection, interviews, subjective interpretation.
- Low trust: idealized self-image, hypothetical answers, unsupported identity narratives.

2. State-Aware
Pierre is not static. Model operating states/modes:
Builder, Strategist, Explorer, Father, Politician, Trader, Flow, Stressed, Exhausted, Threatened.

3. Falsifiable
Every major claim must allow counter-evidence and conditions where it is not true.

4. Practical > Elegant
Prefer 90% useful and operational over 99% elegant but never finished.

5. Established Models Matter
Existing psychological models are relevant, but they describe Pierre; they do not define Pierre.

6. Versioned & Living
The model must support updates, contradictions, growth, changing states and new evidence.

Layer 6 — High-Fidelity Representation Layer
How Pierre thinks, prioritizes, decides, detects bullshit, communicates, draws ethical boundaries.

Layer 7 — Evolution Layer
Every major claim includes confidence %, evidence, counter-evidence, when true, when false, last verified, update triggers, confidence decay.

## Success Criteria
1. Feels uncomfortably accurate.
2. Explains major historical decisions.
3. Predicts failure modes earlier.
4. Improves decision quality.
5. Becomes practically useful.
6. A third party says: “This sounds disturbingly like Pierre.”

## Constraints
Avoid endless refinement, perfectionism before usefulness, overbuilding, elegant theory replacing reality, excessive abstraction without evidence.

## First Build Phase
Start with Layer 0, Layer 1, Layer 2.
Layer 3–7 come after enough evidence exists.
